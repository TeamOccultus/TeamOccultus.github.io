# 隐藏之年 3.0.10

<!-- more -->
> [!WARNING]
> 对 1.21.130 ~ 26.21 版本的支持即将结束，届时你仍可以在这些版本中游玩已有版本的隐藏之年，但**无法接受到可用的更新**

## 新内容与修改
- 更新了红宝石守卫的模型与纹理 
- 更新了沙蚀蠹虫的模型与纹理 
- 为沙蚀蠹虫添加了花哨变种并优化其战利品表 
- 移除了主包中的荒沙行歌和盛战序幕曲目（被转移到OST包中）
- 现在合成归乡晶石与归途晶石需要更多的魔法源质和钻石 

## 弃用
- 弃用了隐年的铜碎片 

## 技术性
- 加入了 hiddenyears:deprecated组件 
- 将大部分生物的格式版本提升到 1.21.130
- 使用原生方法使敌对生物在和平模式下消失 
- 移除了红宝石僵尸与试炼僵尸的无用组件 

## 修复
- 修复了农田遗迹引用了不存在的结构池的问题 
- 修复了原版铜粒纹理错误的问题 
- 修复部分金属碎片可以燃烧的问题 
- 修复了怪物不会随距离消失的问题 
- 修复了红宝石王冠效果一直会生效的问题
