# 魔法酿造
## 魔法酿造台

进行魔法酿造的功能性方块，通过 **8个魔法源质 + 酿造台** 合成获取。


## 初级酿造

初级魔药可通过以下两种方式获得：

1. **炼金台炼制**：附魔之瓶 + 对应植物原料 + 7个魔法源质
2. **魔法酿造台炼制**：水瓶 + 对应植物原料 + 1个魔法源质

## 高级酿造

### 第一步：获取粗制的魔药

在魔法酿造台上使用 **水瓶 + 魔酿基质** 酿造获得。

### 第二步：添加效果

使用与原版相同的酿造材料，为粗制魔药添加效果：

- 每种效果时长为 **10分钟**
- 多种效果之间可以**叠加**

### 效果强化（可选）

通过**闪耀之石**可使高阶魔药获得强化：

- 效果时长延长至 **15分钟**
- 效果等级**翻倍**
- 该强化效果每瓶魔药仅可应用一次
