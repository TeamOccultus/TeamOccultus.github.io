# 获取饰品

在冒险途中，除了之前提到过的职业与技能，一套合适的**饰品**也是提升的关键。

## 获取饰品

对于普通饰品，可以通过「试炼之石」获取。

![](/artifact_2.png)

你可以在「秘宝地牢」或「战斗高塔」中找到它们，下图展示的就是晨光中的战斗高塔。

![](/artifact_1.png)

使用试炼之石刷取饰品的过程如下：

1. 开启试炼：与试炼之石交互，它会召唤出一波怪物，击败这些怪物并注意收集它们掉落的**晶片碎屑**
2. 兑换奖励：当你收集够 9 个「晶片碎屑」后，在炼金台上将其合成为一个**契约晶片**，手持「契约晶片」再次与试炼之石交互，你将获得随机一件饰品，该试炼之石随后熄灭
3. 重置试炼：对熄灭的试炼之石使用**魔法的尘埃**，即可使其重新回到「等待」状态，开始下一轮刷取

需要注意的是，BOSS 生物掉落的饰品不能通过这个途径获得。

## 饰品类型

你共有 5 个饰品装备槽可用，可以根据需求自由搭配：

- 头饰：主要提供视觉增益、特殊概率触发或生活技能加成
- 身体：主要提供生存向的增益或防御反击能力
- 手饰：主要强化攻击端的表现，或为攻击附加特殊效果
- 脚饰：主要提供机动性上的提升
- 符文：提供极其强大且往往带有一定代价的能力

## 常见饰品
### 头饰

| 饰品名称 | 核心效果 | 推荐场景 |
| :--- | :--- | :--- |
| 战士兜鍪 | 攻击概率造成额外真实伤害 | 近战输出首选，无视防御 |
| 海眷之面 | 获取潮涌能量 | 水下探索或战斗 |
| 闪耀之面 | 获取夜视 | 深入地下洞穴、夜间探险 |
| 牧者草帽 | 击杀禽畜额外掉落生肉 | 生存玩家 |
| 农夫草帽 | 收割作物额外掉落物品 | 种田玩家 |

### 身体

| 饰品名称 | 核心效果 | 推荐场景 |
| :--- | :--- | :--- |
| 隐身斗篷 | 获取隐身 | 选择刺客职业的玩家 |
| 烈焰斗篷 | 获取防火 | 下界探险或对抗火焰法术 |
| 荆棘斗篷 | 受击时反弹荆棘伤害 | 近战缠斗 |
| 勇者徽章 | 提升最大生命值 | **全职业通用**，提升容错率的万金油选择 |
| 魔羽斗篷 | 获取缓降 | 空岛探险 |

### 手饰

| 饰品名称 | 核心效果 | 推荐场景 |
| :--- | :--- | :--- |
| 狂战手套 | 必定造成额外伤害，概率反噬伤害 | 狂战士玩家 |
| 诅咒指环 | 赋予敌人缓慢 | 控制流，让敌人寸步难行 |
| 矿工手套 | 挖掘方块获急迫 | 挖矿时大幅提升效率 |

### 脚饰

| 饰品名称 | 核心效果 | 推荐场景 |
| :--- | :--- | :--- |
| 速度之靴 | 获取速度 | **全职业通用**，跑图赶路必备 |
| 狡兔之靴 | 获取跳跃提升 | 跨越复杂地形 |

### 符文

符文通常具有改变战局的力量，但也可能伴随代价：

| 饰品名称 | 核心效果 | 推荐场景 |
| :--- | :--- | :--- |
| 十字符文 | 受击概率必定回复生命值，概率回满血 | 绝境逢生，大幅提高容错率 |
| 受囚之翼 | 攻击时对周遭范围内(非BOSS)造成真实伤害 | 适合被小怪包围时使用，群伤极其恐怖 |
| 饕餮符文 | 以饥饿为代价，获得力量 | 需要大量食物支撑 |

## 饰品的销毁

倘若刷取了太多同类型饰品，可以在工作台或炼金台将其销毁为魔法的尘埃或者魔法源质。

你可以在流浪商人处可以交换一些常见的饰品。
