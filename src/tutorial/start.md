# 开始冒险

欢迎踏上隐藏之年的旅程，行旅者（Voyager）！

在这片广袤而孤独的大地上，仅存的智慧生物就是你，你将在探索中一步步揭开这个世界隐藏的奥秘……

## 做好准备

在开局时，你应当收到了下面这三种物品：时匿怀表、行旅晶石和一卷残破的羊皮纸。

![](/start_1.png)

其中，时匿怀表是游戏的核心物品，提交任务、查看教程与图鉴都需要在这里面进行。

行旅晶石则可以为你提供一个基础的职业——「行旅者」，这个职业虽然不能为你提供任何加成，却是获取后续职业的基础。

而这卷残破的羊皮纸上面似乎写着什么字，试着使用它来看看吧！

## 探索世界

使用残破的羊皮纸后，你会发现前辈给你留下的叮嘱。

打开时匿怀表，你会发现整个怀表被划分为了「游戏功能」、「图鉴」和「关于」三个板块：

![](/start_2.png)

在游戏功能的任务一栏中，你可以查看需要做的任务，需要注意的是，这些任务虽然按照序章、第一章、第二章进行了分类，但并没有严格的执行顺序。

而在饰品、职业两栏中，你可以管理自己身上佩戴的饰品，对自己的职业进行升级或者是转职。

最后，在货币兑换一栏中，你可以将身上的**魔法能源**兑换为货币。

> **魔法能源**是隐藏之年引入的一种新机制。
> 
> 你可以将其理解为其他模组的魔力值，在释放魔法时你需要消耗一定的魔法能源，使用货币、魔法尘埃或者魔法源质可以获得魔法能源。

在图鉴的两栏中，你可以查看教程、阅读背景故事。

那么接下来，使用行旅晶石获得基础职业，跟随着时匿怀表中的「任务」一栏，开始探索未知的世界吧！
