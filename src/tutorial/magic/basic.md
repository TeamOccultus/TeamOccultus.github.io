# 魔法基础

欢迎踏入魔法的世界，新晋的行旅魔法师！在接下来的几页中，我们将会一同探索瑰丽的魔法世界。

## 基础材料

**魔法尘埃**是所有魔法配方的基础，通过分解红宝石获得。

**魔法源质**则是更高级的原材料，需通过炼金台将魔法尘埃与金锭融合而成：

![](/magic_1.png)

在魔法世界中，你还需要获取三个重要的功能性方块：

- 炼金台，由红宝石和木板合成而来，是魔法入门的第一件工具
- 魔法酿造台，由魔法源质和石头合成而来，可用于炼制复合药水
- 魔法锻造台，由魔法源质和铁锭合成而来，可用于打造和升级高级装备

![](/magic_2.png)

## 魔法能源

**魔法能源**是储存在你体内的魔力的直观体现，释放魔法时往往需要消耗魔法能源。

使用货币、魔法尘埃或者魔法源质可以为自己补充魔法能源。

在时匿怀表的「货币兑换」栏目中，你可以将魔法能源兑换为货币。
