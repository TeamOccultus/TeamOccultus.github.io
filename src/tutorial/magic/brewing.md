# 魔法酿造

通过神奇的魔法，许多看似不起眼的材料都能迸发出不一样的力量。

## 初级酿造

初级魔药在**炼金台**上炼制，使用水瓶、对应植物原料和 1 个魔法源质即可获取初级魔药。

| 魔药名称 | 植物原料 | 效果 |
|----------|----------|------|
| 饱和魔药 | 蒲公英 | 去除反胃、饥饿效果；给予120秒**饱和** |
| 镇痛魔药 | 虞美人 | 去除所有负面效果；给予120秒**伤害吸收** |
| 明视魔药 | 兰花 | 去除黑暗、失明效果；给予100秒**夜视** |
| 「明视」魔药 | 绒球葱 | 给予100秒**黑暗**、**失明**；去除夜视 |
| 解毒魔药 | 蓝花美耳草 | 去除凋零、中毒、致命中毒；给予100秒**伤害吸收** |
| 力量魔药 | 郁金香 | 给予120秒**力量II**；去除虚弱 |
| 兴奋魔药 | 滨菊 | 给予120秒**迅捷III**；去除缓慢 |
| 跳跃魔药 | 矢车菊 | 给予120秒**跳跃提升III**；去除缓慢 |
| 微毒魔药 | 铃兰 | 给予玩家**中毒**100秒 |
| 剧毒魔药 | 凋零玫瑰 | 给予玩家**凋零**120秒、**虚弱**120秒、**缓慢**120秒 |
| 灵药 | 火把花 | 给予玩家20秒**所有正面效果** |
| 灵惑魔药 | 瓶子草 | 去除不祥之兆；给予玩家**村庄英雄**120秒 |
| 海眷魔药 | 海草 | 去除挖掘疲劳；给予玩家**水下呼吸**100秒 |

## 高级酿造
使用魔法酿造台和魔法源质，我们可以为一瓶药水添加上多种效果。

首先，我们需要获得一瓶没有任何效果的复合药水，这需要在原版酿造台上使用魔法源质酿造得到：

![](/magic_7.png)

接下来，把手持酿造原料与魔法酿造台交互，再手持复合药水与魔法酿造台交互即可为复合药水添加上对应原料的状态效果。

每种效果时长为 10 分钟，多种效果之间可以相互叠加，但是单种效果不能重复添加。

> 这里的「酿造原料」与原版保持一致，请参阅[中文 Minecraft Wiki](https://zh.minecraft.wiki/w/%E8%8D%AF%E6%B0%B4%E9%85%BF%E9%80%A0?variant=zh-cn#%E5%BD%B1%E5%93%8D%E6%9D%90%E6%96%99)。
